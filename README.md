# True North Travels  
A modern, minimalistic and immersive website dedicated to Scandinavian travel experiences.

## 🌍 About the Project
True North Travels is a visually rich and content-driven website introducing users to authentic Scandinavian adventures.  
The project focuses on clean design, smooth animations, and structured travel programs.  
The goal is to create an inspiring digital experience that reflects the beauty, calmness and mystery of the Nordic region.

The website includes:
- Detailed travel descriptions  
- Program tables and schedules  
- Animated sections on scroll  
- User registration & sign-in pages  
- Responsive layout for all devices  
- Multilingual support (EN / RU)

---

## ✨ Features

### 🔹 Smooth Scroll Animations  
Using `IntersectionObserver`, elements gracefully fade/slide into view as the user scrolls.

### 🔹 Fully Responsive Design  
Works perfectly on phones, tablets, laptops and large screens.

### 🔹 Clean & Modern UI  
Scandinavian-inspired color palette, soft shadows, rounded blocks and minimalistic typography.

### 🔹 Separate Pages
- **Home page**  
- **Programs page**  
- **Popular tours section**  
- **Reviews block**  
- **Registration page**  
- **Sign-in page**

### 🔹 Organized content  
Includes detailed descriptions of:
- Norway Fjords  
- Lapland Northern Lights  
- Scandinavian capitals  
- Adventure & cultural experiences
